# ApexEngineer — 1-Click Native Desktop App

When you extract `ApexEngineer-Windows.zip`, ignore the technical folders (`dist`, `dist-server`, `scripts`) and use the files right at the top:

- **`ApexEngineer.exe`** — **Double-click to launch** in a fast native Windows desktop window with the ApexEngineer icon (no Chrome window, no console window, built-in LMU & UDP `:5606` listener).
- **`Create_Desktop_Shortcut.bat`** — Optional 1-click Desktop & Start Menu shortcut creator with the ApexEngineer icon.
- **`00_ADD_API_KEY_HERE.txt`** — Optional free Gemini API key for Gemini Live voice & AI debriefs.
- **`01_START_HERE.txt`** — Quick-start instructions in plain English.
- **`03_START_LMU_BRIDGE.bat`** — Optional standalone bridge for forwarding telemetry to a remote URL.

*(On macOS/Linux: `./start-local.sh`)*
